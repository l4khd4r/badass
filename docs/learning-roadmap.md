# BADASS Learning Roadmap

## P1 — Foundation

1. Ethernet, MAC addresses, IPv4 and subnetting.
2. Linux network interfaces, bridges and routing.
3. Docker images, containers and network capabilities.
4. GNS3 topology construction and connectivity testing.
5. Routing software and protocol services.

## P2 — VXLAN

1. Understand Layer 2 versus Layer 3 forwarding.
2. Configure a Linux bridge.
3. Configure VXLAN VNI 10 in static mode.
4. Configure VXLAN multicast mode.
5. Inspect forwarding databases and verify connectivity.

## P3 — BGP EVPN

1. Understand the underlay and overlay distinction.
2. Establish OSPF underlay connectivity.
3. Configure BGP sessions and a route reflector.
4. Configure EVPN over VXLAN without MPLS.
5. Verify EVPN route types 2 and 3 and MAC learning.
